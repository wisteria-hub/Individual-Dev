# Qualyx

資格（Qualification）の取得状況を **スキルツリー形式** で可視化する Web アプリです。
ITパスポート → 基本情報技術者 → 応用情報技術者 → 高度試験 のように、下位資格から上位資格への
前提関係をツリー状に表示し、各資格を「未着手 / 学習中 / 取得済み」で管理できます。

## 特徴

- 資格の前提関係（依存関係）を DAG としてツリー描画（SVG、外部ライブラリ不使用）
- 3段階のステータス管理（未着手 / 学習中 / 取得済み）
- 取得状況はブラウザの `localStorage` に保存（key: `qualyx-progress-v1`）
- カテゴリ（分野）による絞り込み
- ライト / ダークテーマ自動対応

## 技術スタック

- React 19 + Vite（JavaScript）
- スタイル: プレーン CSS + CSS 変数（`src/index.css` にデザイントークン）

## セットアップ

> **注意（開発環境）**: このプロジェクトは **パスに日本語（マルチバイト文字）を含むフォルダ配下では
> Node.js がクラッシュする**ため、`C:\dev\Qualyx` のような ASCII のみのパスで実行してください。

```bash
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開きます。

その他のコマンド:

```bash
npm run build     # 本番ビルド（dist/）
npm run preview   # ビルド結果のプレビュー
npm run lint      # oxlint
```

## 資格データの追加・編集

資格マスターは静的データとして管理しています（UI からの編集機能はありません）。
新しい資格・分野を追加するには次の2ファイルを編集します。

- `src/data/categories.js` — 分野（カテゴリ）の定義
- `src/data/qualifications.js` — 各資格の定義

各資格のフィールド:

| フィールド | 説明 |
|---|---|
| `id` | 一意なキー。**進捗の保存キーにも使うため、既存の id は変更しない**（変更すると保存済み進捗と紐付かなくなる） |
| `name` | 表示名 |
| `category` | `categories.js` の `id` |
| `prerequisites` | 前提となる資格 `id` の配列（複数指定可。空配列なら起点） |

存在しない前提の参照や循環参照は、起動時に検出して `console.warn` で警告し、
該当エッジを無視してアプリは継続動作します（`src/domain/buildGraph.js`）。

## データの扱いについて

- 掲載する資格名・カテゴリ名などのサンプルは、一般に公開されている資格情報のみを用います。
- 個人を特定できる情報や実在の個人データは登録しません。
- 取得状況は各利用者のブラウザ内（`localStorage`）にのみ保存され、外部へ送信されません。
